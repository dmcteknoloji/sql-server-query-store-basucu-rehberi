# Contributing / Katkı

**English.** The most useful contribution is a correction backed by a measurement. Open an issue with the SQL Server build (`SELECT @@VERSION`), edition, what you ran, the output you got and the page or chapter of the handbook you think is wrong. Pull requests for scripts are welcome if the script still runs on the versions listed in the README, and the output you attach comes from your own run. The handbook text and PDFs are maintained by the author, so text changes go through an issue.

**Türkçe.** En değerli katkı ölçümle desteklenmiş bir düzeltmedir. Bir issue açın ve şunları yazın: SQL Server build numarası (`SELECT @@VERSION`), edition, ne çalıştırdığınız, aldığınız çıktı ve kitapta yanlış bulduğunuz bölüm ya da sayfa. Betik düzeltmeleri için pull request kabul edilir, betik README'de yazılı sürümlerde çalışmalı ve eklediğiniz çıktı kendi çalıştırmanızdan olmalıdır. Kitap metnini ve PDF'leri yazar yönetir, metin değişiklikleri issue üzerinden gider.

Before you run any script, read the warnings in the README. Betikleri çalıştırmadan önce README'deki uyarıları okuyun.
